# FitCloud Mobile Fitness Tracking System

## Project Overview
FitCloud is a cloud-based fitness tracking web application designed to help users monitor and manage their daily fitness activities. The system allows users to track workouts, monitor water intake, calculate BMI, and view real-time fitness analytics through an interactive dashboard.

This project is developed as part of a Cloud Computing assignment using Firebase as the backend cloud platform.

## Features
- User Registration & Login (Firebase Authentication)
- Workout Tracking (Add / View / Update / Delete)
- Water Intake Tracker
- BMI Calculator
- Dashboard with Real-time Analytics
- User Profile Management
- Real-time data updates using Firebase Firestore

## Cloud Computing Technologies Used

### Firebase Services
- Firebase Authentication (Secure login system)
- Cloud Firestore (NoSQL real-time database)
- Firebase Hosting (Cloud deployment with HTTPS)
- Firebase SDK (Frontend–Backend integration)

### Architecture
- Serverless Cloud Architecture
- Platform as a Service (PaaS)
- Public Cloud Deployment

## Security Features
- Firebase Authentication for secure login
- UID-based user data separation (each user can only access their own data)
- Firestore security rules for data protection
- HTTPS encryption via Firebase Hosting

## Cloud Features
- Real-time database synchronization using Firebase Firestore
- Serverless backend (no manual server management required)
- Scalable cloud storage (Firestore NoSQL database)
- Global access via Firebase Hosting CDN
